# Анализ датчиков RayDesk

Jupyter-ноутбук **sensor-temperature.ipynb** — температурная характеристика датчиков очков RayNeo:
какие датчики и насколько «врут» при разных температурах и сколько это даёт ухода мира.

## Запуск

```sh
./run.sh          # первый раз сам создаст .venv через uv
```

В открывшемся JupyterLab — `sensor-temperature.ipynb` → Kernel → Restart & Run All.

## Данные

Ноутбук читает `~/Library/Logs/RayDesk-imu` (пишутся автоматически при работе RayDesk):

| файл | частота | содержимое |
|---|---|---|
| `imu-*.csv` | 500 Гц | сырой IMU **до обработки в приложении**: аксель (g), гироскоп (°/с), `temp` — термодатчик чипа (°C), магнитометр. Хранятся последние 4 файла (~2 дня) |
| `glasses-*.csv` | ~30 Гц | камера: `headingError` — курс IMU минус курс по камере (°), `cameraYawStep` — доворот мира за кадр (°), `score` — совпадение формы (доля), `speed` — скорость головы (°/с) |

Гироскоп в `imu-*.csv` — сырые показания прошивки очков: они квантованы шагом 0.035 °/с, и прошивка
периодически пересчитывает своё смещение нуля. Приложение умеет это отменять (`FirmwareZeroRestorer`) —
пункт меню **Камера → «Отменять пересчёты нуля гироскопа прошивкой»**, по умолчанию включён; при переключении ноль гироскопа переучивается заново — минуту мир может вести.
В логах до 07.10 21:30 восстановитель был выключен, поэтому скачки нуля в них видны как есть.

## Что внутри

1. **Обзор сессий и кривые прогрева** — температурные рампы дают разброс для всех фитингов.
2. **Гироскоп: биас в покое vs T** — среднее гироскопа в сегментах неподвижности = биас напрямую (без опоры). Наклон = дрейф биаса на °C; вертикальная ось gy = уход курса.
3. **Акселерометр vs T** — модуль (масштаб) и крен/тангаж из гравитации (наклонная ошибка → питч/ролл мира).
4. **Магнитометр vs T** — модуль (чувствительность) и курс (наклоны считаются только внутри сессии с ΔT ≥ 0.5 °C).
5. **Камера как абсолютная опора** — `true_rate = derr − step_sum` — скорость уплывания курса до коррекций (остаточная, после компаса); зависимость от температуры (биас) и от скорости поворота (масштаб гироскопа).
6. **Полки: уход курса vs положение головы** — окна, где камера видит неподвижную голову, и разница «вертикальная скорость гироскопа минус курс по камере» по полосам курса: сколько курс уезжает, пока голова стоит в стороне.
7. **Уход мира относительно комнаты** — курс из кватерниона головы минус курс по камере по сессиям: насколько картинка разошлась с комнатой.
8. **Пересчёты нуля прошивкой** — сколько раз, когда и на сколько прошивка сдвинула ноль гироскопа, и что это даёт курсу.
9. **Сводка** — °/ч на °C по каждому датчику + проекция «уход за час при ΔT=8°».
10. **Методика чистого эксперимента** — охладить очки → 5 мин покоя → 15 мин работы с метками ⌃⌥M; после него ячейки 2–4 заполнятся реальными коэффициентами.

## Файлы

- `sensor-temperature.ipynb` — сам ноутбук (коммитится с выводами, чтобы смотреть без запуска).
- `sensorlib.py` — загрузка логов, детект неподвижности, фиты (импортируется ноутбуком).
- `build_notebook.py` — генератор ноутбука: правки ячеек делаются здесь, потом `/usr/bin/python3 build_notebook.py`.
- `run.sh` — запуск JupyterLab (создаёт `.venv` при отсутствии).
