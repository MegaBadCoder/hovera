# Как учится ноль гироскопа — интерактивная презентация

Откройте `index.html` в браузере. Интернет не нужен: Three.js лежит рядом в `three.min.js`.

Что внутри:

- модель датчика, интегрирование ориентации, матрица вида;
- окна покоя и обучение нуля (StillnessBiasLearner, VectorBiasLearner);
- пересчёты нуля прошивкой и восстановитель (FirmwareZeroRestorer);
- ограничения поправок компаса и камеры (CameraAlignment);
- измеренный наклон нуля по температуре и примеры увода в градусах;
- живая лаборатория: экран в мире, слайдеры истинного нуля и температуры, учитель,
  пересчёт прошивкой, поворот головы и график «истинный ноль / оценка / увод».

Файлы: `index.html`, `lab.js`, `three.min.js`.
