## Design
Отчёт по конкурентам (XRealDesk, Fusion, XRLinuxDriver, Monado) и замеры в очках: экраны «не всегда держатся», пульс даёт дрожь, One Euro отстаёт на медленных движениях, оценка смещения по компасу гуляет ±0,5 °/с. Изменения — только через стенд-реплей записей с тремя метриками: дрожь (отрисованная ориентация минус чистый гироскоп, полоса 0,5–5 Гц, спокойные участки), отставание (то же, участки движения), дрейф (уход курса на спокойных участках записи с каруселью).

1. Разделение «оценка / что рисуем»: поправки наклона и компаса вливаются в отрисовку со скоростью 0,03/с в покое + 1,5·|ω| в движении (XRealDesk) — против дрожи от пульса через акселерометр.
2. Предсказание по сглаженной ω (ФНЧ 8 мс), а не по последнему отсчёту.
3. Смещение нуля гироскопа по всем осям в покое: детектор покоя по разбросу сырых данных (не по отличию от текущей оценки), быстрый путь ±0,4 °/с, длинный путь для скачков после поправки оправы; сохранение между запусками.
4. Акселерометр: отбраковка по углу ошибки (10°) с восстановлением (Fusion), плавный старт.
5. «Поводок» вместо One Euro.
6. Компас — медленный якорь курса.

TDD: yes (стенд + юнит-тесты на каждый блок)

### Invariants
- Метрики на записях не хуже main ни по одной оси, а целевая улучшается.
- main и его сборка не меняются до слияния.
- Старые тесты (медленные повороты не поглощаются, «память» фильтра, карусель с компасом) проходят.
