# Режим медитации

**Status:** done
**Branch:** meditation-mode
**Worktree:** .worktrees/meditation-mode
**Mode:** interactive

## Design

По ⌃⌥Z мониторы плавно гаснут, вокруг по всей сфере проявляется космос, звучит спокойная музыка в духе brain.fm. Повторное ⌃⌥Z возвращает всё как было. Космос держится трекингом головы, как экраны, поэтому ощущается как пространство вокруг, а не картинка перед глазами.

### Картинка — космос, процедурно в Metal

- Отдельный проход перед экранами: треугольник на весь экран, фрагментный шейдер по направлению взгляда пикселя в мировых осях (обратная проекция × ориентация головы) рисует небо.
- Звёзды: хеш по ячейкам сферы, разная яркость и цвет, лёгкое мерцание. Туманности: fbm-шум от направления, 2–3 цвета, очень медленный дрейф. Внизу полупрозрачная планета с атмосферной каймой — ориентир, что сфера неподвижна.
- Без картинок и чужих ассетов, без швов на сфере, работает при любом угле обзора.
- Переход 3 с: небо проявляется, экраны гаснут (в конвейер экранов добавляется прозрачность). Когда экраны полностью скрыты, они не рисуются.
- Альтернатива — готовая панорама (equirect-текстура). Отвергнута: нужна лицензия на картинку, заметен шов и полюса, весит мегабайты.

### Звук — генерируется в программе

- `AVAudioEngine` + `AVAudioSourceNode`, звук синтезируется по отсчётам в реальном времени, стерео 48 кГц, на системный выход.
- Слои:
  - пэды: несколько слегка расстроенных синусов/треугольников, медленная смена аккордов (раз в ~16 с, с плавным переходом), без мелодии, мягкий фильтр;
  - волны: розовый/коричневый шум через фильтр с медленными случайными «накатами» 7–12 с, разнесённые по стереобазе;
  - «нейроэффект» как у brain.fm: ритмичная амплитудная модуляция музыки (не волн) с частотой 6 Гц; сила — выкл / слабый / средний / сильный (глубина 0 / 0,15 / 0,3 / 0,5).
- Появление и затухание 4 с, без щелчков. Пик не выше −1 dBFS.
- Эффективность «нейроэффекта» не обещаем: это приём, похожий на brain.fm, а не их технология.
- Альтернативы: свой файл (нет готовой музыки у пользователя без настроек), встроенный трек (поиск лицензии, вес). Отвергнуты для первой версии.

### Дыхание — опция

- Светящееся кольцо перед «вперёд» (центр мира, где стоят экраны), в том же шейдере неба: 4 с расширяется (вдох), 6 с сужается (выдох), мягкое свечение.
- Включается в меню «Медитация → Дыхание», по умолчанию выключено, запоминается.

### Управление

- ⌃⌥Z — включить / выключить (клавиша свободна).
- Меню «Медитация»: «Включить / выключить ⌃⌥Z», «Дыхание» (галочка), «Нейроэффект» (выкл / слабый / средний / сильный). Настройки в `UserDefaults` (`meditationBreathing`, `meditationNeuralEffect`).
- Во время медитации курсор за взглядом не прыгает; MacBook и мышь работают как обычно. Захват экранов продолжает работать, чтобы выход был мгновенным.

### Где что лежит

- `RayDeskCore/MeditationSession.swift` — чистая логика: фаза перехода (0…1) по времени, фаза дыхания, громкость. Тестируется.
- `RayDeskCore/AmbientSynth.swift` — синтез в буфер `Float` по отсчётам, детерминированный от зерна. Тестируется без звуковой карты.
- `RayDesk/MeditationAudio.swift` — `AVAudioEngine`, подключает `AmbientSynth`.
- `Renderer.swift` — проход неба, прозрачность экранов, uniforms (время, переход, дыхание).
- `AppDelegate.swift` — ⌃⌥Z, меню, настройки, пауза прыжков курсора.

Обратная совместимость: новая функция, существующие настройки и клавиши не меняются.

TDD: yes — `MeditationSession` и `AmbientSynth` (тайминги, отсутствие перегруза, глубина модуляции на 6 Гц, плавность затухания). Шейдер и `AVAudioEngine` — ручная проверка в очках.

### Invariants

- Вне медитации кадр рисуется как раньше: проход неба не выполняется, экраны непрозрачны.
- Синтезатор не выделяет память и не берёт блокировки в звуковом потоке рендера.
- Выход звука никогда не превышает −1 dBFS; включение и выключение без щелчков (громкость меняется плавно).
- Во время медитации `CursorWarpPolicy` не переносит курсор по взгляду.

### Principles

- Всё генерируется кодом: без чужих картинок, треков и сэмплов.
- Логика, которую можно проверить числом, живёт в `RayDeskCore` и покрыта тестами; платформенный код тонкий.

## Plan

Approach: чистая логика и синтез в `RayDeskCore` через тесты, затем тонкий слой звука, проход неба в `Renderer` и управление в `AppDelegate`.

### Phase 1 — логика сеанса
- **1.1** `Sources/RayDeskCore/MeditationSession.swift` (create)
  - `struct MeditationTransition { isActive; progress (0…1); eased; mutating toggle(); mutating advance(by:) }` — переход 3 с, сглаживание smoothstep.
  - `enum Breathing { static let inhaleSeconds = 4, exhaleSeconds = 6; static func openness(at:) -> Double }` — 0 выдохнуто, 1 вдохнуто.
- **1.2** `Tests/RayDeskCoreTests/MeditationSessionTests.swift` (create) — длительность и монотонность перехода, разворот посреди перехода, фазы дыхания 0/4/10 с, период 10 с.
- Commit: `Режим медитации: переход и дыхание`

### Phase 2 — синтезатор
- **2.1** `Sources/RayDeskCore/AmbientSynth.swift` (create)
  - `enum NeuralEffect: String { off, low, medium, high; depth }`
  - `struct AmbientSynth { init(sampleRate:seed:); targetVolume; neuralEffect; mutating render(left:right:frames:) }` — пэды (4 аккорда, смена 16 с с переходом 4 с), волны (шум, накаты 7–12 с), АМ 6 Гц только на музыке, рампа громкости 4 с, мягкое ограничение ≤ −1 dBFS. Состояние фиксированного размера, без выделений в `render`.
  - `static func neuralGain(time:depth:) -> Double`.
- **2.2** `Tests/RayDeskCoreTests/AmbientSynthTests.swift` (create) — пик ≤ 0,891, тишина при громкости 0, плавное нарастание без щелчка, детерминизм по зерну, пульсация 6 Гц растёт с силой эффекта.
- Commit: `Режим медитации: синтезатор фонового звука`
- Invariant: пик ≤ −1 dBFS, плавная громкость, без выделений в рендере.

### Phase 3 — приложение
- **3.1** `Sources/RayDesk/MeditationAudio.swift` (create) — `AVAudioEngine` + `AVAudioSourceNode`; параметры (громкость, сила эффекта) через `Synchronization.Atomic`, без блокировок в звуковом потоке; `start()`, `stop()` (затухание, затем остановка движка).
- **3.2** `Sources/RayDesk/Renderer.swift` (modify) — `var meditation: MeditationTransition`, `var breathingEnabled`; проход неба `skyVertex/skyFragment` (звёзды, туманности, планета, кольцо дыхания) только при `eased > 0`; прозрачность экранов через смешивание, экраны не рисуются при полной медитации; сетка скрыта в медитации.
- **3.3** `Sources/RayDesk/AppDelegate.swift` (modify) — ⌃⌥Z `toggleMeditation`, подменю «Медитация» (вкл/выкл, «Дыхание», «Нейроэффект»), настройки `meditationBreathing` и `meditationNeuralEffect`, в `onFrame` при медитации не вызывать `warpPolicy.observeGaze` и `warpTarget` возвращает `nil`.
- Commit: `Режим медитации: космос, звук и управление ⌃⌥Z`
- Invariant: вне медитации кадр как раньше; курсор не прыгает в медитации.

## Conclusion

Outcome: режим медитации (⌃⌥Z: космос, генерируемый звук, дыхание) и наклон экранов ⌃⌥⇧↑/↓ — ветка `meditation-mode`, 0467887.

Invariants:
- вне медитации кадр как раньше — проход неба только при `skyAmount > 0`, экраны с непрозрачностью 1; подтверждено ревью
- синтезатор без выделений и блокировок в рендере — ревью; параметры через `Atomic`
- пик ≤ −1 dBFS, плавная громкость — тесты `AmbientSynthTests`
- курсор не прыгает в медитации — `observeGaze`/`warpTarget` пропускаются при `meditation.isActive`

### Deviations from plan
- Космос переделан по отзыву «слабоватый, хочу как в EVE»: объёмные туманности считаются один раз при входе и запекаются в кубическую карту 1024², каждый кадр рисуются звёзды, солнце, планета с атмосферой и кольцами. Медленный дрейф туманностей снят: движение всего неба ощущалось бы как уход картинки; живыми остались мерцание звёзд и облака планеты.
- Добавлен наклон экранов (`ScreenPose.tilt`, ⌃⌥⇧↑/↓, ⌃⌥⇧ + скролл) по просьбе пользователя; старые раскладки читаются с наклоном 0.
- Фазы выполнены в основной сессии без отдельных исполнителей.
