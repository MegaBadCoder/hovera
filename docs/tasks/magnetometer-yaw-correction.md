**Worktree:** none
**Mode:** interactive (дизайн и план — автоапрув пользователя)

## Design

**Проблема.** На голове ноль гироскопа по вертикали −0,2…+0,3 °/с и меняется скачком при поправлении очков (на столе ≈0) — мир крутится «каруселью» ~12°/мин. Акселерометр вертикаль не видит, автокалибровка нуля в `OrientationFilter` самоблокируется: условие покоя `|smoothed − bias| < 0,2 °/с` сравнивается с текущей оценкой, и при настоящем нуле 0,26 °/с не выполняется никогда (анализ `tmp/session3.csv`, 10 мин с магнитометром).

**Решение.** Магнитометр очков — медленный наблюдатель смещения нуля по вертикали, а не прямая подтяжка курса.
- Декодер отдаёт магнитометр в осях тела: `mag_body = (m_y, −m_x, m_z)` из полей 36, 32, 52 кадра; кадры-заглушки (±3200) отбрасываются. Температура тоже в сэмпле.
- Разовая калибровка компаса (hard-iron): пользователь 20–30 с крутит головой, сфера аппроксимируется МНК → центр, радиус, наклон поля к гравитации (dip); проверка охвата направлений и разброса радиуса. Сохраняется в UserDefaults `magCalibration.v1`. Без калибровки наблюдатель выключен, в меню — «компас не откалиброван».
- Наблюдатель: горизонтальная составляющая поля в мировых осях должна стоять на месте; угол её ухода от опорного направления → PI-регулятор вокруг мировой вертикали (P τ≈20 с, I τ≈60 с — оценка смещения нуля по вертикали). Гейт: `| |m−c|/R − 1 | < 3 %` и dip в пределах ±5° от калиброванного; вне гейта — P выключен, оценка I заморожена. ⌃⌥R (`alignYawToZero`) поворачивает опорное направление вместе с миром.
- Автокалибровка нуля в покое больше не сравнивает с текущей оценкой (устраняет самоблокировку); критерий подбирается по данным так, чтобы медленные повороты головы по-прежнему не поглощались (тесты сохраняются).

**Отвергнуто.** Прямая подтяжка курса к компасу (шум и искажения поля тянули бы картинку); компенсация по поправкам ⌃⌥R (уже пробовали — шум ±9° раскачивает).

**Неизвестные.** Как поведёт себя поле рядом с другими магнитами (колонки, телефон) — гейт должен замораживать; достаточно ли 20–30 с кручения для охвата сферы (у агента в фоне было 45/69 диаметра).

TDD: yes (декодер, сфера, наблюдатель, критерий покоя — чистые функции; реплей записи с каруселью как регрессионный тест)

### Invariants
- Без калибровки компаса поведение фильтра по курсу не меняется (наблюдатель выключен).
- Наблюдатель поворачивает мир только вокруг вертикали; наклон по-прежнему только от акселерометра.
- Вне гейта поля (искажение) оценка смещения не меняется.
- ⌃⌥R не создаёт скачка наблюдателя: опорное направление поворачивается вместе с миром.
- Core — только Foundation, simd, CoreGraphics.

### Principles
- Без тихих фолбэков: плохая калибровка (мало охвата, большой разброс) отвергается с сообщением, а не сохраняется.
- Константы с говорящими именами; единицы — радианы, секунды, микротесла не предполагаются (единицы магнитометра неизвестны, работаем в «сырых»).

## Plan

Approach: сначала данные (декодер, фикстура), затем по TDD калибровка сферы и наблюдатель в Core, потом критерий покоя, в конце обвязка приложения и проверка в очках.

### Phase 1 — Магнитометр в декодере и фикстура
- `Sources/RayDeskCore/RayNeoProtocol.swift` (modify) — `IMUSample.magnetometer: SIMD3<Double>?` (оси тела), `temperature: Double`; заглушки ±3200 → `nil`.
- `Tests/RayDeskCoreTests/Fixtures/carousel.csv.lzfse` (create) — фрагмент `tmp/session3.csv` с каруселью и скачком нуля, сжатый LZFSE; хелпер чтения фикстур в тестах.
- Тесты: реальные кадры A (заглушка → nil) и B (поле → оси тела).

### Phase 2 — Калибровка компаса (Core)
- `Sources/RayDeskCore/MagnetometerCalibration.swift` (create) — `struct MagnetometerCalibration: Codable { center, radius, dip }`, `struct HardIronFitter { mutating add(mag:gravity:), result() -> Result<MagnetometerCalibration, CalibrationError> }` (МНК-сфера, охват по направлениям, разброс радиуса).
- Тесты: синтетическая сфера с шумом; недостаточный охват → ошибка; фикстура → центр ≈(−77, 21, −29), радиус ≈34,4.

### Phase 3 — Наблюдатель по вертикали (Core)
- `OrientationFilter` (modify) — `magnetometerCalibration: MagnetometerCalibration?`, `update(gyro:accel:magnetometer:dt:)`, PI по углу ухода горизонтального поля, гейт, `alignYawToZero` поворачивает опору, `public var verticalBias` (рад/с) для лога.
- Тесты: синтетический ноль 0,25 °/с по вертикали + идеальное поле → курс перестаёт уходить; искажение поля → оценка заморожена; ⌃⌥R без скачка; без калибровки — поведение прежнее; реплей фикстуры: в спокойных окнах уход < 1°/мин (без наблюдателя ≈ −11°/мин).

### Phase 4 — Автокалибровка нуля без самоблокировки
- `OrientationFilter.trackBias` (modify) — критерий покоя не зависит от текущей оценки; параметры по данным фикстуры.
- Тесты: ноль 0,26 °/с в покое на столе выучивается; существующие тесты медленных поворотов проходят.

### Phase 5 — Приложение
- `GlassesIMU` — передаёт магнитометр в фильтр.
- `AppDelegate` — ⌃⌥K «Калибровка компаса» (20–30 с сбора, голосовая/текстовая подсказка через лог и алерт с результатом), загрузка/сохранение `magCalibration.v1`, статус «компас ✓/✗» и оценка нуля в строке меню и логе.
- Коммит на каждую фазу.

### Open questions / risks / rollback
- Если охват за 30 с окажется мал — удлинить сбор или подсказывать направления.
- Откат: ветка `magnetometer-yaw-correction`, наблюдатель выключается удалением калибровки.

Positive:
- `swift test` — 90 тестов; реплей записи с каруселью: уход курса 24° без компаса → 1° с компасом.

Invariants:
