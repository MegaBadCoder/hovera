## Design

Экраны собираются вокруг головы дугой, край к краю, как тройной монитор у гонщиков. Два способа, оба выбраны пользователем:

- **Магнит при перетаскивании (⌃⌥ + мышь).** Если боковой край перетаскиваемого экрана подходит к боковому краю соседа ближе 3° и экраны стоят примерно на одной высоте, экран прилипает: встаёт вплотную, берёт у соседа высоту взгляда (pitch), расстояние и наклон. Рамки обоих подсвечиваются. Чтобы оторвать, тащить дальше: прилипание считается от «свободной» позы, накопленной мышью, поэтому за порогом экран отпускается сам.
- **«Собрать дугой» (⌃⌥A и меню).** Все экраны в текущем порядке слева направо встают вплотную вокруг направления взгляда, на одном расстоянии (медиана текущих), на высоте взгляда, без наклона; ширина каждого сохраняется.

Экраны плоские. Прилипание угловое: края совпадают для взгляда из головы. Половина угловой ширины экрана по горизонтали — `atan(width / 2 / (distance · cos pitch))`.

Альтернатива — изогнутые экраны без стыков — отложена по выбору пользователя.

Обратная совместимость: раскладки не меняют формат; прежняя «Собрать экраны перед собой» остаётся.

TDD: yes — вся геометрия в `RayDeskCore/ScreenSnap.swift` и `SpatialScene.arrangeInArc`.

### Invariants
- Без соседа в пределах порога поза при перетаскивании та же, что раньше (`dragged`).
- Прилипший экран касается соседа краем без зазора и перекрытия (в угловой мере).
- «Собрать дугой» сохраняет порядок экранов слева направо и их ширины.

### Principles
- Геометрия — чистые функции в `RayDeskCore` с тестами; приложение только вызывает их.
