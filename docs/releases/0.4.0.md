# Hovera 0.4.0

## Русский

Hovera поддерживает RayNeo Air и VITURE Luma Ultra в одном приложении RayDesk для macOS на Apple Silicon.

- Независимая перепроекция обновляет вид по свежей позе головы, не ожидая нового кадра рабочего стола или полной сцены.
- Вывод и виртуальные дисплеи запрашивают до 120 Гц для обоих семейств очков; фактический режим определяется macOS.
- VITURE получает позу через callback официального SDK. Экстраполяция включена по умолчанию, позиционный 6DoF и слияние гироскопа выключены.
- Экспериментальная компенсация развёртки использует разные прогнозы для верха и низа экрана. Её можно сравнить включённой и выключенной в одной сессии.
- Возвращено доступное меню «Картинка → Стабилизация картинки → Выключена / Слабая / Средняя / Сильная». При закреплении это сглаживание только в покое; выбор силы отключает обходящий его Adaptive VSync. Без закрепления уровни управляют общим фильтром ориентации.
- Добавлены настройка порога покоя, статус на сфере, отдельные программные тайминги сцены и перепроекции. Подготовка текстур захвата и управление SDK разгружают путь отрисовки.

### Установка

Распакуйте `Hovera-0.4.0-macOS-arm64.zip` и переместите `RayDesk.app` в «Программы». Библиотеки VITURE включены в архив; исходники SDK не входят в Git. Закройте SpaceWalker перед запуском. Разрешите запись экрана и универсальный доступ; камера нужна для необязательных функций трекинга камерой.

Приложение пока не нотаризовано: при блокировке первого запуска используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

### Проверка и ограничения

512 core-тестов и 8 тестов локализации прошли, включая реальный GPU-тест построчной проекции и управление уровнями стабилизации. Перед публикацией проверяются подпись, версия bundle, состав ZIP и SHA-256.

Компенсация развёртки экспериментальна: её значение по умолчанию — сверху вниз за один период обновления, 8,33 мс при 120 Гц. Реальное время свечения строк не измерено. Дополнительный прогноз ограничен бюджетом трекера и может стать нулевым при насыщении горизонта. Плавность зависит от нагрузки Mac; полное подавление пульса не гарантируется. Другие модели VITURE и надёжное перемещение по комнате не заявлены.

## English

Hovera 0.4.0 adds VITURE Luma Ultra support alongside RayNeo Air, independent rotational reprojection, up to 120 Hz output, and experimental per-row scanout compensation.

The Picture stabilisation submenu is available again. With world lock enabled, Off / Weak / Medium / Strong controls the existing stillness-only filter. Selecting a strength disables Adaptive VSync, which bypasses that filter; anchoring and scanout compensation remain enabled. Without world lock, the levels control the general orientation filter.

Download `Hovera-0.4.0-macOS-arm64.zip`, extract `RayDesk.app` and move it to Applications. Apple Silicon and macOS 15 or later are required. The VITURE runtime libraries are included. Close SpaceWalker before running Hovera. Grant Screen Recording and Accessibility; Camera permission is needed for optional camera tracking features. The app is not notarized; use Privacy & Security → Open Anyway if macOS blocks the first launch.

Validation: 512 core tests and 8 localization tests, including offscreen GPU reprojection and menu behavior. Scanout uses an experimental top-to-bottom one-period model; optical timing has not been measured. The tracker prediction budget may reduce or disable the row correction. Frame pacing depends on system load, and complete heartbeat suppression is not guaranteed. Other VITURE models are not validated.
