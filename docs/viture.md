# VITURE Luma Ultra

Hovera получает ориентацию Luma Ultra через официальный VITURE XR Glasses SDK для macOS arm64. Проверенная модель — USB `35ca:1104`; поддержка других моделей этим путём не подтверждена.

## Установка

В архив Hovera 0.4.0 включены `libglasses.dylib` и `libcarina_vio.dylib`. Для готовой сборки отдельно устанавливать SDK не требуется. Перед запуском завершите SpaceWalker и другие приложения, использующие трекер очков.

## Сборка из исходников

Получите macOS arm64 XR Glasses SDK с [официального портала VITURE](https://www.viture.com/developer). Положите обе библиотеки в `Vendor/viture/aarch64` или передайте `VITURE_SDK_DIR` — каталог, непосредственно содержащий эти файлы.

```bash
VITURE_SDK_DIR="/path/to/sdk/aarch64" ./build.sh
open /Applications/RayDesk.app
```

`build.sh` помещает библиотеки в `RayDesk.app/Contents/Frameworks` и подписывает их вместе с приложением. SDK не хранится в Git и не покрывается лицензией MIT проекта. Без него можно собрать приложение для RayNeo, но трекинг VITURE будет недоступен.

## Трекинг и стабилизация

Поза приходит через callback SDK. Экстраполяция включена по умолчанию; перемещение по 6DoF и слияние с гироскопом выключены. Закрепление при поворотах не требует включать позиционный трекинг. При недостоверной или устаревшей позе прогноз ограничивается.

В меню «Картинка» уровни стабилизации при закреплении управляют сглаживанием только в покое. Выбор силы отключает Adaptive VSync; закрепление и компенсация развёртки сохраняются. [Описание режимов](../README.ru.md#стабилизация).

Приложение запрашивает физический режим 1920×1200 около 120 Гц и виртуальные мониторы 120 Гц. Фактическая частота зависит от доступных macOS режимов и нагрузки. Тайминги и состояние трекинга записываются в `~/Library/Logs/RayDesk.log`; `SCANOUT span=0` означает, что дополнительная построчная поправка сейчас не применяется.

⌃⌥R задаёт новое направление вперёд. ⌃⌥C включает ручную настройку сцены: с зажатыми ⌃⌥ стрелки меняют курс и вертикальный угол, запятая и точка — крен. Повторное ⌃⌥C завершает настройку.
